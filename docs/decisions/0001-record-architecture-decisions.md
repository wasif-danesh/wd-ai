# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-07

## Context

The platform will grow over years and across many products. Decisions made in chat get lost.

## Decision

Record significant decisions as short ADRs in `docs/decisions/`, numbered sequentially, using this format (Status, Context, Decision, Consequences). Statuses: Proposed, Accepted, Superseded by ADR-NNNN. Create new ones with the `/new-adr` Claude Code command.

## Consequences

- Claude Code and humans can check intent before changing designs.
- Accepted ADRs are not edited; they are superseded by new ones.
